# Homebrew tap for Tamebar

[Tamebar](https://github.com/pFournet/tamebar) keeps your Mac calm while AI coding agents run. This
repository holds only its Homebrew cask; the source, the releases and the install script live in
[pFournet/tamebar](https://github.com/pFournet/tamebar).

```sh
brew trust pfournet/tamebar && brew install --cask pfournet/tamebar/tamebar
```

Or without Homebrew:

```sh
curl -fsSL https://raw.githubusercontent.com/pFournet/tamebar/main/install.sh | sh
```

Updating, uninstalling and the "Apple could not verify Tamebar" message are covered in
[Installing Tamebar](https://github.com/pFournet/tamebar/blob/main/docs/INSTALL.md).
